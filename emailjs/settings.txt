EmailJS 템플릿 설정 (template_8dglgra)
================================

[왜 dashboard 와 repo 가 다를까?]
  - EmailJS 대시보드: 예전 카드형 템플릿 (WEDDING CUE SHEET, 입장 음원·타이밍 등)
  - repo template.html: 인쇄용과 동일하게 표 HTML만 ({{{mc_cue_sheet}}})
  - 코드 배포만으로 EmailJS Content 는 자동 변경되지 않습니다.
    대시보드를 직접 갱신해야 합니다.

[Settings 탭]
  To Email   : {{to_email}}
  From Name  : ENX 웨딩 · MC
  Reply To   : tseizou@naver.com
  Subject    : {{subject}}

[Content 탭 — 이렇게 바꾸세요]
  1. 기존 HTML 전부 삭제
  2. template.html 내용 복사 (실제로는 아래 한 줄)
  3. HTML 모드 ON → 붙여넣기 → Save

  붙여넣을 내용:
  {{{mc_cue_sheet}}}

  ※ 중괄호 3개 {{{ }}} — HTML 표가 그대로 렌더링됩니다.
  ※ {{mc_cue_sheet}} (2개)는 HTML이 깨지거나 텍스트로 보입니다.

[Preview 테스트용 샘플]
  to_email       : tseizou@naver.com
  subject        : [ENX 웨딩 · MC] 홍길동 · 김미영 — 2026년 9월 10일
  mc_cue_sheet   : (앱 전송 시 표 + 파란 「인쇄」 버튼 자동 포함)

[예전 템플릿]
